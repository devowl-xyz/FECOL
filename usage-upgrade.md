# Usage Upgrade Ideas

1. Ability to use imported 3d models (OBJ or FBX) and edit them
2. Ability to create 3d models (polygons, icosphere, and sculpting)
3. Texture painting
4. Activate Editing mode by holding one open hand and one fist. The open hand will be the editing tool, and as long as the other hand is in fist mode, we can edit the shape:

a. Open hands for rotating and manipulating freely the model
b. one finger to sculpt
c. two fingers to scale by pivot point
d. three fingers to flatten
